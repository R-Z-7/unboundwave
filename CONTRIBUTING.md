# Contributing
Use Node 22.12+, run `npm ci`, `npm run dev`, and the backend described in README. Before proposing a change run `npm test` and `npm run build`. Include a focused explanation and tests for authentication, encryption, recovery or message state changes. Never add logs containing private keys, tokens or message contents. Keep preview data explicitly labelled. Do not claim delivery/read without acknowledgements or encryption for public rooms. Follow the code of conduct. Propose protocol changes against linked upstream NIPs; prefer maintained libraries to new cryptography.

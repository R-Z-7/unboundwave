# Roadmap
First release completion: hardened authentication and sessions, live Google acceptance testing, authenticated relay connections, complete NIP-29 authoritative metadata and supported role/moderation UI, encrypted reactions, persistent privacy controls, enforced invite expiry where supported, full offline/public-room queues and mobile PWA validation.

Later, outside first-release scope: encrypted private groups, encrypted attachments, voice notes, device linking, temporary event rooms.

Bluetooth mesh messaging requires a future native companion; browsers are not promised offline phone-to-phone delivery.
